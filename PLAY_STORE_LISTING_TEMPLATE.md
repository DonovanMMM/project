## Full Description

Book of Mormon Mobile helps you explore scripture text quickly.

Core features:
- Search words and phrases across verses.
- View title statistics by book.
- Generate pie and line chart views for title usage.
- Designed for simple, mobile-first study workflows.

The app is built for reliable Android use and supports offline chart-image fallback when network chart fetch is unavailable.
